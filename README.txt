GreenMarket — Bootstrap 5 loyiha

Ishga tushirish:
1. ZIP faylni arxivdan chiqaring.
2. GreenMarket papkasini VS Code orqali oching.
3. index.html faylini brauzerda oching yoki Live Server ishlating.

Sahifalar:
- index.html — bosh sahifa
- products.html — mahsulotlar, qidiruv, kategoriya filtri va narx bo‘yicha saralash
- product-details.html — mahsulot tafsilotlari (?id=1 ... ?id=8)
- cart.html — savatcha va buyurtma modal oynasi
- about.html — loyiha haqida, aloqa formasi va FAQ

Modal oynalar:
- Kirish
- Ro‘yxatdan o‘tish
- Buyurtmani rasmiylashtirish
- Toast xabarlari

Texnologiyalar:
- HTML5, CSS3, JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons
- localStorage orqali demo savatcha

Eslatma:
Kirish, ro‘yxatdan o‘tish va buyurtma funksiyalari frontend demo holatida ishlaydi.
Haqiqiy akkauntlar va buyurtmalar uchun backend hamda ma’lumotlar bazasi kerak.
Rasmlar internetdan yuklanadi, shuning uchun internet aloqasi zarur.
